## 🛠 Troubleshooting

### Gantt chart not displaying

```powershell
# Switch to Gantt Chart view
# View > Gantt Chart (or click Gantt Chart button on ribbon)

# Reset view
# View > Reset to Default > Gantt Chart

# Check date range
# Zoom out if tasks outside visible date range
```

### Critical path incorrect

```powershell
# Verify task dependencies
# Check predecessor/successor relationships correct

# Enable critical path display
# Format > Critical Tasks (checkbox)

# Check constraints
# Task > Information > Advanced > Remove hard constraints (Must Start On)
```

### Resource over-allocation

```powershell
# Level resources automatically
# Resource > Level All

# Manual leveling
# View > Resource Usage > Identify over-allocated resources > Adjust assignments

# Increase resource availability
# Resource Sheet > Max Units = 100% (or hire more resources)
```
